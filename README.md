Клиент Mihomo для Android: подключение по вашей подписке одной кнопкой, тариф, срок, трафик и
объявления провайдера — сразу на главном экране. Сделан под панель Remnawave. Внутри —
[Clod Core](https://github.com/Mrvibecodic/clod-core), наш форк стабильного
[mihomo](https://github.com/MetaCubeX/mihomo). Android 6.0 и новее.

Версия для Windows, macOS и Linux — в репозитории
[clod-clash](https://github.com/Mrvibecodic/clod-clash).

## Провайдеру

- [Настройка панели](https://mrvibecodic.github.io/clod-clash-android/ru/docs/provider/panel) —
  правило в Subscription response rules Remnawave.
- [Заголовки подписки](https://mrvibecodic.github.io/clod-clash-android/ru/docs/provider/headers)
  и [заголовки clod-*](https://mrvibecodic.github.io/clod-clash-android/ru/docs/provider/clod-headers).
- [Ядро Clod Core](https://mrvibecodic.github.io/clod-clash-android/ru/docs/provider/core) —
  чем оно отличается от стокового mihomo.

## Основа и лицензия
