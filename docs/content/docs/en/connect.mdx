## Connecting

Tap the big button on the home screen. The first time, Android asks for the VPN permission —
without it the tunnel cannot start.

Once connected, the button turns green with the session timer inside, and below it you see what
was downloaded and uploaded during the session.

<Callout title="The reminder on your first connection">
Once, the app shows a "Keep the connection from dropping" reminder with links to the system
battery and always-on VPN settings. Without them Android may put the tunnel to sleep. The same
items live in **More → Connection** later.
</Callout>

## Picking a server

The **Selected server** row (**Connected to** once connected) opens the **Servers** tab with the
list from the subscription. A tap selects a server; you can pick one before connecting too.

<Shot src="en/servers.png" alt="The Servers tab: servers with their latency" />

- **Latency** is the number on the right: green up to 200 ms, yellow up to 400 ms, red beyond
  (the provider can set its own bounds). A grey dash means the server did not answer or has not
  been checked yet.
- **The star** adds a server to favourites — favourites move to the top.
- **The lightning bolt** in the header measures latency again: the open group first, then the
  others in the background. Without a connection latency is measured directly.

With two or three groups, switches appear above the list; with more, a drop-down. The selected
server of every group can be shown on the home screen: **More → Look and behavior → All groups
on Home**.

<Callout title="Marks instead of milliseconds">
If the provider turned latency numbers off, you see a check mark (the server answers), a cross
(it did not answer) or a dash (not checked yet).
</Callout>
