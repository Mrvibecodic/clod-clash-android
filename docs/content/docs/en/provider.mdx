This page is for those who run a Remnawave panel. Users do not need to do anything here.

## Response rule for the client

The app introduces itself as `ClodClash/<version> (Android)`. Without a rule of its own the panel
returns its default answer instead of a mihomo config, and the subscription will not be added.

In **Subscription response rules** add a rule: regular expression `^clodclash` (case does not
matter), response format **MIHOMO**. The same rule serves the desktop version too.

To show each server's **Server description** under its name, add `^ClodClash/` to
`responseModifications.additionalExtendedClientsRegex` in the same rule — as a prefix, otherwise
the rule breaks with the next app update.

```json
{
  "name": "Mihomo Clients",
  "description": "Response with generated YAML config (Mihomo Template)",
  "enabled": true,
  "operator": "AND",
  "conditions": [
    {
      "headerName": "user-agent",
      "operator": "REGEX",
      "value": "^(?:FlClash|FlClashX|Flowvy|[Cc]lash-[Vv]erge|[Kk]oala-[Cc]lash|[Cc]lash-?[Mm]eta|[Mm]urge|[Cc]lashX [Mm]eta|[Mm]ihomo|[Cc]lash-nyanpasu|clash.meta|prizrak-box|[Cc]lod[Cc]lash)",
      "caseSensitive": false
    }
  ],
  "responseType": "MIHOMO",
  "responseModifications": {
    "additionalExtendedClientsRegex": [
      "^ClodClash/"
    ]
  }
}
```

<Callout title="How to check">
Request the subscription link with `User-Agent: ClodClash/0.0.1 (Android)`: you should get mihomo
YAML, and the nodes should carry a `serverDescription` field.
</Callout>

The MIHOMO template and the keys the client overrides are in the
[panel setup guide](https://github.com/Mrvibecodic/clod-clash/blob/main/docs/REMNAWAVE.md).
Response headers are on the [Subscription headers](/en/docs/headers) and
[clod-* headers](/en/docs/clod-headers) pages.

## Secure connection

If the user turned on "Secure connection", the subscription is requested through a separate
encrypted channel rather than a plain HTTPS request. This works only if the provider supports
such a channel on their side; otherwise the app reports that the address has no subscription
with a secure channel.

## Network stack

The tunnel stack is taken from the template: `tun.stack` (with `tun.enable: true`) or `stack` on
a `type: tun` listener. `system`, `gvisor`, `mixed` and `mips` are accepted, other values are
skipped. Without a stack in the template — `mips`. The stack the user picks in
**More → Network → Stack mode** wins over the template.
