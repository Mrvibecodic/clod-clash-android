Clod Clash is an Android client that brings up a secure connection from a subscription link.
The [mihomo](https://github.com/MetaCubeX/mihomo) core is bundled with the app, so there is
nothing extra to install or update.

<Shot src="en/home.png" alt="Home screen: subscription, connect button, traffic and expiry left" />

## How it works

Your provider gives you a **subscription link**. The app downloads the server list and routing
rules from it, then brings up a system tunnel so that the phone's traffic goes through the
server you picked. Server list, remaining traffic and expiry date come from the same
subscription and are refreshed automatically.

## What the app can do

- A device-wide tunnel, or a local proxy without VPN.
- Manual server choice, automatic pick by latency, favourites.
- A list of apps that bypass the tunnel (or, the other way round, the only ones that use it).
- Dark theme, Russian and English, a home-screen widget and a quick-settings tile.
- Built-in updates that ship the core along with the app.
