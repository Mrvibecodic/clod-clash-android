All settings are on the **More** tab. If the provider sent links, a block with the subscription's
name sits on top: "Customer portal", "Support", "Bot", "Server status", "Setup guide".

<Shot src="en/more.png" alt="The More tab: connection, app, help" />

## Connection

**Mode** — rules, global or direct (see [Modes](/en/docs/modes)).

**Apps** — which apps go through the tunnel: "Allow all apps", "Allow selected apps" or
"Deny selected apps". If the subscription sends its own lists, they are applied as is.

**Unrestricted battery** and **Always-on connection** lead to Android's system settings: the
first stops the system from killing the app in the background, the second keeps the VPN up at
all times. The current state is shown next to each.

**Network** — tunnel options:

| Setting | What it does | Default |
| --- | --- | --- |
| Route system traffic | A device-wide tunnel; off — only a local proxy | on |
| Bypass private network | The local network and printers stay reachable directly | on |
| DNS hijacking | Catches any DNS request to port 53, IPv6 included | on |
| Allow bypass | Apps that bind to a network themselves (some messengers, banks) can go around the VPN | off |
| Allow IPv6 | Let IPv6 through the tunnel | off |
| System proxy | Tell apps the proxy address (Android 10 and newer) | on |
| Stack mode | How traffic is captured, see [Modes](/en/docs/modes#network-stack) | Auto |
| Drop connections when the network changes | On Wi-Fi ⇄ mobile data switches apps reconnect right away | on |
| Keep the tunnel active while the screen is off | Keeps the CPU awake. Noticeably drains the battery; needed if the server drops idle connections | off |

## App

**Look and behavior**:

- **Dark mode**, **Language**, **Group icons**, **All groups on Home**;
- **Start after reboot** — bring the tunnel back after a phone reboot and an app update if it
  was on;
- **Hide app icon** and **Hide from recents**;
- **Show traffic** — a counter in the notification every second (drains the battery);
- **Identify this device** — send the provider a device identifier (for device limits); on by
  default;
- subscription update notifications and **Subscription reminders**;
- **Allow external control** — lets Tasker, MacroDroid and the like turn the tunnel on and off;
  off by default;
- **Back up subscriptions** / **Restore subscriptions**;
- **Reset settings** — subscriptions stay.

**Hiding the icon** removes the app from the launcher. You can still open it with a **long press
on the quick settings tile** (a short tap only toggles the tunnel) or through the app info in
the system settings — add the tile beforehand. App shortcuts are disabled while the icon is
hidden. TVs and Android 6 do not have this setting.

**Core features** — sniffer, config overrides, loading your own geo files. For those who know
what they are changing.

DNS is set in **Core features → Override → DNS**, the **Strategy** item:

| Value | What happens |
| --- | --- |
| Do not modify | DNS from the subscription. If it has none — the built-in set below |
| Use built-in | The subscription's DNS is replaced with the built-in one: `1.0.0.1`, `8.8.4.4`, `9.9.9.10` and the system resolver, fake-ip mode |
| Force enable | If the subscription has no DNS — the core's defaults: `redir-host` and the core vendor's public resolvers (Chinese ones included); requests go to them from the phone's IP |

**Append system DNS** adds the carrier's DNS to the subscription's servers: whoever answers first
wins.

**Routing data and providers** — routing data (countries, sites, networks) and the
subscription's providers; each has its own update button, the header has "Update all". Providers update at once,
new routing data applies after reconnecting.
