Clod Clash — приложение для Android, которое подключает телефон к VPN-сервису по ссылке-подписке.
Ядро [Clod Core](https://github.com/Mrvibecodic/clod-core) — наш форк стабильного
[mihomo](https://github.com/MetaCubeX/mihomo) — встроено в приложение и обновляется вместе с ним.
