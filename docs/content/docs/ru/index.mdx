Clod Clash — клиент для Android, который поднимает защищённое соединение по ссылке-подписке.
Ядро [mihomo](https://github.com/MetaCubeX/mihomo) встроено в приложение, отдельно ставить
и обновлять его не нужно.

<Shot src="ru/home.png" alt="Главный экран: подписка, кнопка подключения, остаток трафика и срока" />

## Как это работает

Провайдер выдаёт вам **ссылку на подписку**. Приложение скачивает по ней список серверов
и правила маршрутизации, а дальше поднимает системный туннель: весь трафик телефона идёт
через выбранный сервер. Список серверов, остаток трафика и срок действия приложение берёт
из той же подписки и обновляет само.

## Что умеет приложение

- Туннель на всё устройство или локальный прокси без VPN.
- Выбор сервера вручную, автовыбор по задержке, избранное.
- Список приложений, которые идут мимо туннеля (или наоборот, только они — через него).
- Тёмная тема, русский и английский язык, виджет и плитка в шторке.
- Встроенное обновление приложения вместе с ядром.
