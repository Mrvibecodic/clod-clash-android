## Какой файл скачать

Все сборки — на [странице загрузки](/ru/download). Имена файлов не меняются от версии к версии,
поэтому ссылка всегда ведёт на последнюю обычную версию:

| Файл | Кому |
| --- | --- |
| `clodclash-arm64-v8a.apk` | Почти всем современным телефонам |
| `clodclash-armeabi-v7a.apk` | Старым 32-разрядным устройствам |
| `clodclash-x86_64.apk` | Эмуляторам и редким планшетам на Intel |
| `clodclash-universal.apk` | Если не знаете, что выбрать: подходит всем, но весит заметно больше |

<Callout title="Как узнать свой вариант">
Телефон куплен после 2019 года — почти наверняка `arm64-v8a`. Ошибиться не страшно:
неподходящий файл система просто не установит.
</Callout>

Приложение работает на Android 6.0 и новее, на телефонах, планшетах и телевизорах с Android TV.

## Установка

1. Скачайте APK на телефон.
2. Откройте файл. Android спросит разрешение устанавливать приложения из этого источника
   (браузера или файлового менеджера) — разрешите.
3. Подтвердите установку и откройте Clod Clash.

Если поверх уже стоит Clod Clash, новая версия ставится поверх — подписки и настройки
сохраняются.

## Какие разрешения попросит приложение

| Разрешение | Когда спросит | Зачем |
| --- | --- | --- |
| VPN | при первом подключении | без него туннель не поднимется |
| Уведомления (Android 13+) | при первом запуске | состояние туннеля и кнопка «Отключить», напоминания о подписке, ошибки обновления, новые версии |
| Работа без ограничения батареи | после первого подключения, по желанию | чтобы Android не останавливал туннель в фоне |
| Установка приложений | при первом обновлении из приложения | чтобы приложение могло обновить само себя |

От уведомлений можно отказаться кнопкой **Не сейчас** — приложение спросит ещё раз через неделю,
а потом перестанет. Пока уведомления запрещены, в настройках «Внешний вид и поведение» висит
предупреждение с кнопкой **Открыть настройки**.

<Callout type="warn" title="Другой VPN">
Android держит только один VPN одновременно. Если включить другой VPN, Clod Clash закроет
туннель и напишет, что разрешение забрало другое приложение. Выключите другой VPN и
подключитесь снова.
</Callout>

## Удаление

Обычным способом — через настройки системы или долгим нажатием на значок. Вместе с приложением
удаляются подписки и настройки. Чтобы потом не искать ссылки, сохраните их заранее:
**Ещё → Внешний вид и поведение → Сохранить подписки** (см.
[«Перенос на другое устройство»](/ru/docs/user/subscription#перенос-на-другое-устройство)).
