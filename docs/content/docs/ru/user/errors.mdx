Приложение всегда пишет причину своими словами. Найдите на этой странице текст, который видите, —
рядом написано, что делать. Если в описании сказано «вопрос к провайдеру», значит, исправить это
может только провайдер: приложение тут ни при чём.

## Подписка не добавляется

Причина появляется красным под полем со ссылкой. Подписка при этом не сохраняется — исправьте
ссылку или дождитесь провайдера и нажмите **Добавить подписку** ещё раз.

<Shot src="ru/add-profile-error.png" alt="Причина ошибки под полем со ссылкой" />

| Текст | Что значит и что делать |
| --- | --- |
| Адрес должен начинаться с https:// | в поле не ссылка или ссылка `http://`. Скопируйте ссылку целиком |
| Ещё загружается другая подписка… | дождитесь, пока закончится предыдущая загрузка |
| Провайдер не нашёл эту подписку (код 404 или 410) | ссылка устарела или скопирована не целиком. Возьмите свежую ссылку в кабинете провайдера |
| Провайдер отказал в доступе (код 401, 402 или 403) | подписка истекла или исчерпан лимит устройств — вопрос к провайдеру |
| У сервера провайдера неполадки (код 5xx) | сбой на стороне провайдера, попробуйте позже |
| Провайдер ответил кодом … | необычный ответ сервера — вопрос к провайдеру |
| Сервер провайдера не отвечает | защищённый канал не ответил три раза подряд, а сетевая причина не распознана (при включении канала у добавленной подписки — и когда сервер отвечает ошибкой 5xx). Попробуйте позже; если повторяется — вопрос к провайдеру |
| Сервер подписки не ответил вовремя | медленный или нестабильный интернет. Попробуйте ещё раз, при необходимости — через другую сеть |
| Не удалось найти сервер подписки по имени | нет интернета, или адрес сменился. Если интернет есть — спросите провайдера о новой ссылке |
| Не удалось подключиться к серверу подписки… | нет интернета или сервер недоступен из вашей сети. Попробуйте позже или через другую сеть |
| Сертификат сервера подписки не прошёл проверку… | проверьте дату и время на телефоне (лучше — «Автоматически»). Если они верны — вопрос к провайдеру |
| Часы устройства сильно расходятся… | включите в настройках Android автоматические дату и время |
| Адрес ответил, но не подпиской… | по ссылке открывается сайт, а не подписка. Проверьте ссылку; если она верна — вопрос к провайдеру |
| В подписке нет ни серверов, ни наборов серверов… | так выглядит истёкшая подписка или исчерпанный трафик — вопрос к провайдеру |
| В настройках подписки ошибка, и ядро их не приняло | провайдер прислал конфигурацию с ошибкой — вопрос к провайдеру |
| Ответ слишком большой для подписки… | по ссылке не подписка — проверьте ссылку |
| Провайдер перенаправил запрос на незашифрованный адрес… | ошибка настройки на стороне провайдера; приложение не отправляет данные в открытом виде |
| Ответ провайдера не прошёл проверку защищённого канала… | попробуйте ещё раз. Если повторяется в разных сетях — сообщите провайдеру: ответ мог быть подменён по пути |
| Провайдер ответил не тем, что понимает защищённый канал… | по адресу не подписка Clod Clash или канал там выключен — вопрос к провайдеру |

## Подписка не обновляется

Ошибки обновления те же, что при добавлении (таблица выше), только приходят уведомлением «Не удалось
обновить» — если не выключены **Ошибки обновления подписки**. Прежние серверы при этом продолжают
работать.

- **«Не обновилась · обновлено …»** на карточке подписки — пропущено одно автообновление.
- Рамка **«Обновите подписку»** на карточке и подсвеченный значок обновления на главном экране —
  пропущено два раза подряд. Нажмите **Обновить** и посмотрите причину.
- **«… обновлена, но не скачалось: …»** — подписка обновилась, но часть наборов серверов и правил не
  скачалась. Обычно проходит при следующем обновлении; если нет — вопрос к провайдеру.
- **Подписка не обновляется при выключенном VPN** — Android ограничивает приложение в фоне. Разрешите
  работу без ограничения батареи: **Ещё → Не ограничивать батарею**.

## Серверов нет

Вместо списка серверов — карточка с причиной на главном экране и на вкладке «Серверы».

<Shot src="ru/expired.png" alt="Карточка «Подписка истекла»" />

| Карточка | Что делать |
| --- | --- |
| **Подписка истекла** | продлите подписку у провайдера (кнопка **Личный кабинет**, если есть). Серверы вернутся при следующем обновлении — нажмите значок обновления в шапке |
| **Трафик закончился** | докупите трафик или дождитесь пополнения — дата пополнения указана, если провайдер её присылает |
| **Превышен лимит устройств** | подпиской пользуется слишком много устройств. Освободить место может только провайдер — обратитесь в его поддержку |
| **Устройство не опознано** | включите **Ещё → Внешний вид и поведение → Опознавать это устройство** (кнопка **Настройки** на карточке) и обновите подписку |
| **Провайдер не выдал серверы** | срок и трафик в порядке, но серверов нет — вопрос к провайдеру |

После продления или пополнения обязательно обновите подписку — сама она обновится только по своему
интервалу.

## Ошибки подключения

| Текст | Что значит и что делать |
| --- | --- |
| Система не открыла запрос разрешения на VPN | попробуйте ещё раз; если повторяется — перезагрузите телефон |
| Разрешение на VPN забрало другое приложение или система… | включили другой VPN. Выключите его и подключитесь снова |
| Не удалось поднять туннель / Система не дала создать туннель | попробуйте подключиться ещё раз; если повторяется — перезагрузите телефон |
| Постоянный VPN не может запуститься, пока включён режим «только прокси» | включите **Ещё → Сеть → Маршрутизировать системный трафик** или выключите постоянный VPN в настройках Android |
| Не удалось применить подписку «…»: … Продолжает работать … | новая версия подписки не принята, работает прежняя. Если вы что-то меняли в **Функции ядра → Переопределение** — сбросьте. Иначе обновите подписку позже или напишите провайдеру |
| VPN-подключение несколько раз подряд пропадало… | система закрывала туннель много раз. Подключитесь снова и снимите ограничение батареи |
| Система перезапустила службу … раза подряд. Автоперезапуск приостановлен… | откройте приложение и подключитесь вручную. Если повторяется — соберите журнал (см. [«Частые вопросы»](/ru/docs/user/faq#как-собрать-журнал)) |
| Система не разрешила запустить службу в фоне… | откройте приложение и подключитесь оттуда; снимите ограничение батареи |
| Пропускать трафик некуда… Трафик заблокирован… | в глобальном режиме нет ни одного скачанного сервера. Обновите подписку или вернитесь в **Режим правил** |
| Не удалось выбрать этот сервер… | список серверов устарел. Обновите подписку и выберите снова |
| Ни один сервер не ответил на проверку | проверьте, работает ли интернет без VPN. Если работает — серверы недоступны из вашей сети, напишите провайдеру |
| Фоновая служба не отвечает… | повторите действие; если не помогает — закройте приложение и откройте снова |

<Callout title="Это не ошибки">
«Система перезапускала фоновую часть приложения — подключение восстановилось само» и «Системный
прокси не объявлен… Сам VPN работает как обычно» — просто сведения. VPN продолжает работать.
</Callout>
