Раздел для тех, кто держит VPN-сервис на панели Remnawave. Пользователю здесь делать ничего не
нужно — для него раздел [«Пользователю»](/ru/docs/user).

## Что сделать

<Steps>
<Step>

**Добавить правило ответа для клиента**, чтобы панель отдавала Clod Clash конфигурацию mihomo, —
[«Настройка панели»](/ru/docs/provider/panel).

</Step>
<Step>

**Отдать заголовки подписки**: название, трафик и срок, интервал обновления, ссылку на поддержку —
[«Заголовки подписки»](/ru/docs/provider/headers).

</Step>
<Step>

**По желанию — собственные заголовки `clod-*`**: личный кабинет, объявления, запасной адрес, замок
режима, проверка серверов 16–20 и другое — [«Заголовки clod-*»](/ru/docs/provider/clod-headers).

</Step>
<Step>

**По желанию — защищённый канал** через прослойку
[remnawave-subscription-middleware](https://github.com/Mrvibecodic/remnawave-subscription-middleware) —
[«Настройка панели»](/ru/docs/provider/panel#защищённый-канал).

</Step>
</Steps>

| Название подписки и логотип в шапке | `profile-title`, `profile-logo` |
| «Активна · 23 дн · 32,0 GiB / 100 GiB», карточки «Трафик» и «Срок действия» | `subscription-userinfo` |
| Объявление под шапкой | `announce` / `clod-announce`, ссылка — `announce-url` |
| Промо-баннер с крестиком | `clod-promo`, `clod-promo-url` |
| Блок ссылок во вкладке «Ещё» | `support-url`, `clod-portal-url`, `clod-bot-url`, `clod-monitor-url`, `clod-guide-url` |
| Кнопки «Личный кабинет» и «Поддержка» на карточке подписки при скором окончании | `clod-portal-url`, `support-url` |
| Интервал автообновления в свойствах подписки | `profile-update-interval` |
| Напоминания о конце срока и трафика | `notify-expire-days`, `notify-traffic-percent` |
| «задан провайдером» у режима | `clod-lock-mode` |
| Цвета задержки или галочки вместо миллисекунд | `clod-ping`, `clod-disable-ping` |
| Подпись протокола у серверов («VLESS RAW (TCP) · Reality») | скрывается `clod-hide-badges`; своё описание — `serverDescription` узла |
| Значок-снежинка у сервера | `clod-16-20-check` |
| Карточки «Превышен лимит устройств», «Устройство не опознано» | `x-hwid-max-devices-reached`, `x-hwid-limit`, `x-hwid-not-supported` |
| Карточки «Подписка истекла», «Трафик закончился», «Провайдер не выдал серверы» | узлы-заглушки панели; показать как есть — `clod-show-0hosts` |

## Что важно знать

- Приложение добавляет подписку только по ссылке `https://` (или диплинку
  `clodclash://install-config?url=…`). Ссылки `http://` не принимаются.
- По умолчанию через туннель не идёт ни одно приложение, пока пользователь их не отметит, — если
  подписка не прислала свой список приложений (`tun.include-package` / `tun.exclude-package`).
  Предупредите пользователей в инструкции или пришлите список исключений: тогда через туннель
  пойдут все приложения, кроме перечисленных. Вернуть прежнее «все приложения» можно заголовком
  [`clod-app-mode: all`](/ru/docs/provider/clod-headers#режим-приложений-clod-app-mode).
- Сетевой стек, режим и прочие параметры приходят из шаблона MIHOMO. Что приложение перезаписывает и
  что оставляет — в [«Настройке панели»](/ru/docs/provider/panel) и
  [«Ядре Clod Core»](/ru/docs/provider/core).
- Ошибки, которые пользователь видит при сбое подписки, перечислены в
  [«Типовых ошибках»](/ru/docs/user/errors) — пригодится поддержке.
