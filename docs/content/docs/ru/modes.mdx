## Туннель или локальный прокси

По умолчанию приложение поднимает туннель для всего устройства. Это переключатель
**Маршрутизировать системный трафик** в **Ещё → Сеть**.

<Shot src="ru/network.png" alt="Настройки сети: переключатель системного трафика и параметры VPN" />

Если его выключить, туннеля нет, а ядро работает как локальный прокси — адрес показан
под переключателем, обычно `127.0.0.1:7890`. Через него идут только приложения, в которых
этот прокси настроен.

<Callout title="Порт прокси">
Порт берётся из подписки. Если она его не задаёт, ставится 7890 — кроме случаев, когда
подписка задаёт свой HTTP-порт или включает `allow-lan` (тогда порт не открывается за вас,
иначе он был бы виден всей сети без пароля). Своё значение — **Ещё → Функции ядра →
Переопределение → Смешанный порт**: пустое поле — не менять, `0` — выключить прокси.
</Callout>

Настройки экрана «Сеть» меняются только при выключенном туннеле (кроме «Разрывать
соединения при смене сети»).

## Режимы маршрутизации

**Ещё → Режим** (есть, когда добавлена подписка):

| Режим | Что делает |
| --- | --- |
| **Режим правил** | Правила из подписки решают, что идёт через сервер, а что напрямую |
| **Глобальный режим** | Весь трафик идёт через сервер из группы `GLOBAL` |
| **Прямой режим** | Туннель поднят, но трафик идёт мимо серверов |

Выбор запоминается для каждой подписки отдельно. По умолчанию режим берётся из подписки.

В глобальном режиме на вкладке «Серверы» важна только группа `GLOBAL`. Если в ней ничего
не выбрано или выбран `DIRECT`, приложение подставляет первый подходящий сервер; если подходящих нет, трафик
блокируется, а не идёт напрямую, — приложение об этом предупредит.

<Callout type="warn" title="Режим может задать провайдер">
Провайдер может закрепить режим за подпиской. Тогда в строке режима стоит «задан вашим
сервисом», и сменить его нельзя. Обычный замок снимается сам, если подписка не обновлялась
больше трёх суток (или трёх интервалов обновления, если интервал длиннее), и возвращается
со следующим удачным обновлением. Бывает и замок без срока.
</Callout>

## Сетевой стек

**Ещё → Сеть → Сетевой стек** — как перехватывается трафик: «Авто (из подписки)»,
«Системный», «gVisor», «Смешанный» или «MIPS». По умолчанию «Авто»: стек из подписки,
а если она его не задаёт — gVisor. Строка **Фактический стек** показывает, какой работает
сейчас. Менять стоит, только если об этом просит провайдер.
