## Подключение

**Режим** — правила, глобальный или прямой (см. [Режимы работы](/ru/docs/modes)).

**Приложения** — какие приложения идут через туннель. Три варианта:

- пропускать все приложения;
- разрешить только выбранные;
- запретить выбранные, остальные пойдут через туннель.

Подписка тоже может прислать свои списки — такие приложения помечены в перечне
и снимать их вручную не нужно.

**Не ограничивать батарею** и **Постоянное соединение** ведут в системные настройки Android.
Первое мешает системе усыплять приложение, второе включает автозапуск туннеля вместе
с телефоном. Оба пункта показывают текущее состояние — «ограничено системой» или «включено».

**Сеть** — параметры туннеля:

| Настройка | Зачем |
| --- | --- |
| Маршрутизировать системный трафик | Туннель на всё устройство или локальный прокси |
| Игнорировать частные сети | Локальная сеть и принтеры остаются доступны напрямую |
| Перехват DNS | DNS-запросы уходят в туннель, а не мимо него |
| Разрешить обход | Даёт другим VPN-приложениям обходить наш туннель |
| Разрешить IPv6 | Пропускать IPv6 в туннель |
| Системный прокси | Сообщать системе адрес прокси (Android 10 и новее) |
| Сетевой стек | Способ перехвата: авто, системный, gVisor, смешанный |
| Разрывать соединения при смене сети | Wi-Fi ⇄ мобильный интернет переживается быстрее |
| Держать туннель активным при выключенном экране | Соединение не засыпает вместе с экраном |

## Приложение

**Внешний вид и поведение** — тёмная тема, язык интерфейса, значки групп из подписки,
скрытие значка приложения, уведомления об обновлениях подписки, сохранение и восстановление
списка подписок.

**Функции ядра** — сниффер, источники баз маршрутизации, переопределение параметров конфига.
Это раздел для тех, кто понимает, что меняет: обычному пользователю сюда заходить незачем.

**Базы и провайдеры** — списки стран, сайтов и сетей, по которым работают правила.
Обновляются кнопкой.

## Помощь

**Помощь** и **Логи**. Логи пригодятся, если соединение ведёт себя странно: их можно
выгрузить в файл и приложить к обращению в поддержку.
