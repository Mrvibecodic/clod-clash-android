Все настройки — на вкладке **Ещё**. Если провайдер прислал ссылки, сверху стоит блок с именем
подписки: «Личный кабинет», «Поддержка», «Бот», «Мониторинг», «Инструкция».

## Подключение

**Режим** — правила, глобальный или прямой (см. [Режимы работы](/ru/docs/modes)).

**Приложения** — какие приложения идут через туннель: «Разрешить все приложения»,
«Разрешить выбранные приложения» или «Запретить выбранные приложения». Если подписка присылает
свои списки, они применяются как есть.

**Не ограничивать батарею** и **Постоянное соединение** ведут в системные настройки Android:
первое не даёт системе останавливать приложение в фоне, второе держит VPN поднятым всегда.
Рядом показано текущее состояние.

**Сеть** — параметры туннеля:

| Настройка | Что делает | По умолчанию |
| --- | --- | --- |
| Маршрутизировать системный трафик | Туннель на всё устройство; выключено — только локальный прокси | вкл |
| Игнорировать частные сети | Локальная сеть и принтеры доступны напрямую | вкл |
| Перехват DNS | Ловит любой DNS-запрос на 53-й порт, включая IPv6 | вкл |
| Разрешить обход | Приложения, которые сами привязываются к сети (некоторые мессенджеры, банки), могут ходить мимо VPN | выкл |
| Разрешить IPv6 | Пропускать IPv6 через туннель | выкл |
| Системный прокси | Сообщать приложениям адрес прокси (Android 10 и новее) | вкл |
| Сетевой стек | Способ перехвата трафика, см. [Режимы работы](/ru/docs/modes#сетевой-стек) | Авто |
| Разрывать соединения при смене сети | При переходе Wi-Fi ⇄ мобильный интернет приложения переподключаются сразу | вкл |
| Держать туннель активным при выключенном экране | Не даёт процессору спать. Заметно расходует батарею; нужно, если сервер рвёт простаивающие соединения | выкл |

## Приложение

**Внешний вид и поведение**:

- **Тёмный режим**, **Язык**, **Иконки групп**, **Все группы на Главной**;
- **Запускать после перезагрузки** — поднимать туннель после перезагрузки телефона
  и обновления приложения, если он был включён;
- **Скрыть значок** и **Скрыть из недавних**;
- **Показывать трафик** — счётчик в уведомлении раз в секунду (расходует батарею);
- **Опознавать это устройство** — отправлять провайдеру идентификатор устройства
  (для лимита устройств); включено по умолчанию;
- уведомления об обновлении подписки и **Напоминания о подписке**;
- **Разрешить внешнее управление** — даёт Tasker, MacroDroid и подобным включать
  и выключать туннель; по умолчанию выключено;
- **Сохранить подписки** / **Восстановить подписки**;
- **Сбросить настройки** — подписки останутся.

**Скрытие значка** убирает приложение из списка программ. Открыть его после этого можно
**долгим нажатием на плитку в шторке** (короткое только включает и выключает туннель) или через
сведения о приложении в настройках системы — добавьте плитку заранее. Ярлыки на значке при этом
отключаются. На телевизорах и на Android 6 настройки нет.

**Функции ядра** — сниффер, переопределение параметров конфига, загрузка своих geo-файлов.
Раздел для тех, кто понимает, что меняет.

DNS настраивается в **Функции ядра → Переопределение → DNS**, пункт **Стратегия**:

| Значение | Что происходит |
| --- | --- |
| Не менять | DNS из подписки. Если его в подписке нет — встроенный набор, как ниже |
| Использовать встроенный | DNS подписки заменяется встроенным: `1.0.0.1`, `8.8.4.4`, `9.9.9.10` и системный резолвер, режим fake-ip |
| Включить принудительно | Если в подписке нет DNS — настройки ядра по умолчанию: `redir-host` и публичные резолверы производителя ядра (в том числе китайские), запросы уходят к ним с IP телефона |

**Добавить системный DNS** добавляет DNS оператора к серверам подписки: выигрывает тот, кто
ответил первым.

**Базы и провайдеры** — данные маршрутизации (страны, сайты, сети) и провайдеры из подписки;
у каждого своя кнопка обновления, в шапке — «Обновить всё». Провайдеры обновляются сразу,
новые базы — после переподключения.
