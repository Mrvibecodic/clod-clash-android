## Какой файл скачать

Сборки лежат на странице релизов в GitHub. Имена файлов не меняются от версии к версии,
поэтому ссылку можно сохранить один раз:

| Файл | Кому |
| --- | --- |
| `clodclash-arm64-v8a.apk` | Почти всем современным телефонам |
| `clodclash-armeabi-v7a.apk` | Старым 32-разрядным устройствам |
| `clodclash-x86_64.apk` | Эмуляторам и редким планшетам на Intel |
| `clodclash-universal.apk` | Если не знаете, что выбрать: подходит всем, но весит вдвое больше |

<Callout title="Как узнать свой вариант">
Если телефон куплен после 2019 года — почти наверняка `arm64-v8a`. Ошибиться не страшно:
несовместимый файл система просто откажется устанавливать.
</Callout>

## Установка

1. Скачайте APK на телефон.
2. Откройте файл — Android спросит разрешение устанавливать приложения из этого источника.
3. Разрешите и подтвердите установку.

Приложению нужно разрешение на VPN (система запросит его при первом подключении)
и, начиная с Android 13, разрешение на уведомления — без него не будет видно
постоянного уведомления с состоянием туннеля.

## Обновления

Приложение проверяет обновления само и показывает окно с описанием изменений.
Проверить вручную: **Ещё → О программе → Проверить обновление**.

Ядро обновляется вместе с приложением — отдельной кнопки для него нет и не нужно.

<Callout type="warn" title="Предварительные сборки">
У предварительных версий в номере есть суффикс, например `0.1.16-alpha`. Такие сборки
приложение предлагает только тем, кто сам включил их приём. Постоянные ссылки на скачивание
всегда ведут на последнюю обычную версию.
</Callout>
