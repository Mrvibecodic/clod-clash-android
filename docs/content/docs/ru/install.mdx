## Какой файл скачать

Все сборки — на [странице загрузки](/ru/download). Имена файлов не меняются от версии к версии,
поэтому ссылка всегда ведёт на последнюю обычную версию:

| Файл | Кому |
| --- | --- |
| `clodclash-arm64-v8a.apk` | Почти всем современным телефонам |
| `clodclash-armeabi-v7a.apk` | Старым 32-разрядным устройствам |
| `clodclash-x86_64.apk` | Эмуляторам и редким планшетам на Intel |
| `clodclash-universal.apk` | Если не знаете, что выбрать: подходит всем, но весит заметно больше |

<Callout title="Как узнать свой вариант">
Телефон куплен после 2019 года — почти наверняка `arm64-v8a`. Ошибиться не страшно:
неподходящий файл система просто не установит.
</Callout>

## Установка

1. Скачайте APK на телефон.
2. Откройте файл — Android спросит разрешение устанавливать приложения из этого источника.
3. Разрешите и подтвердите установку.

При первом подключении система попросит разрешение на VPN. На Android 13 и новее приложение
попросит ещё разрешение на уведомления — без него не видно уведомления с состоянием туннеля,
напоминаний о подписке и ошибок обновления.

## Обновления

Приложение раз в сутки само проверяет обновления и показывает окно с описанием изменений.
Всё это — в **Ещё → О программе**: **Проверить обновление** (вручную), **Проверять
автоматически** (включено по умолчанию) и **Пре-релизы** (выключено).

<Callout type="warn" title="Пре-релизы">
У предварительных версий в номере есть суффикс, например `0.1.22-alpha.6`. Приложение
предлагает их, только если включён переключатель **Пре-релизы**. Постоянные ссылки
на скачивание всегда ведут на последнюю обычную версию.
</Callout>

## Ядро

Ядро обновляется вместе с приложением, отдельной кнопки для него нет. Сейчас внутри —
[Clod Core](https://github.com/Mrvibecodic/clod-core), наш форк стабильного
[mihomo](https://github.com/MetaCubeX/mihomo) v1.19.31. Пять правок в нём сделаны для Android:

- пока сеть переключается или приложение стояло во сне, неудачные проверки не записываются
  узлам — живые серверы не помечаются мёртвыми;
- при смене сети сбрасываются общие сессии узлов (smux, anytls, tuic, hysteria2, gRPC, ssh) —
  новые соединения не садятся на мёртвую сессию прежней сети;
- серверы в группах ручного выбора проверяются с тем же ожидаемым кодом ответа, что задан
  в группе;
- если адрес подписки или провайдера перенаправляет с `https` на `http`, загрузка отклоняется,
  а не уходит в открытом виде;
- уборка памяти ядра идёт после того, как оно перешло в рабочий режим, а не до.

### Clod Core

В Android встроена ветка `android` Clod Core (на ПК это ядро тоже можно выбрать). Кроме правок
выше, в нём:

- **Свежий сетевой стек MIPS** — с исправлениями TCP и ICMP; «Авто» по умолчанию берёт его.
- **Новая библиотека TLS-отпечатков** — utls v1.9.0-mod-meta: отпечатки Firefox 148 и
  Safari 26.3 с постквантовым ключом, исправления возобновления TLS-сессий. Отпечатки chrome,
  ios и edge не меняются.
- **Узлы не «мигают» мёртвыми.** Если плановая проверка группы зависла или оборвалась, через
  секунду идёт вторая; мёртвым узел считается, только если не ответили обе. Закрытый порт,
  несуществующее имя или не тот код ответа — узел мёртв сразу. Проверка по кнопке на экране
  «Серверы» идёт одной попыткой.
- **Нестабильный узел проигрывает стабильному.** Автовыбор добавляет к задержке узла штраф —
  четверть тайм-аута за каждый провал в трёх последних проверках.
- **Меньше лишних проверок.** Узел, который стоит в нескольких группах, проверяется один раз
  за раунд, а узлы на одном сервере — с шагом 250 мс, а не залпом, чтобы блокировщик не принял
  проверки за атаку.
- **Базы не портятся при сбое.** Наборы правил, провайдеры и geo-базы записываются через
  временный файл: если запись оборвалась, старый файл остаётся целым.
